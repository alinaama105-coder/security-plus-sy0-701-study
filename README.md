Common Malware

Virus

Malicious code that attaches itself to files and can spread when executed.

Worm

Malware capable of spreading across networks without requiring the same level of user interaction as a traditional virus.

Trojan

Malicious software disguised as legitimate software.

Ransomware

Malware designed to encrypt or otherwise deny access to data and demand payment.

Rootkit

Designed to maintain privileged or hidden access to a system.

Phishing Investigation

When reviewing a suspicious email, I would check:

- Sender address
- Display name
- Email domain
- Links
- Attachments
- Urgency or unusual language
- Requests for credentials
- Header information where available

Suspicious attachments or links should not be opened directly during an investigation.
